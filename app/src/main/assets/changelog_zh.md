# 更新日志

## 1.4.1

- 小红书图文和封面优先使用官方无水印图片源，不再下载带“小红书”水印的 H5 预览图。
- 图片源标识缺失或异常时增加安全回退。
## 1.4.0

- 批量下载支持一键全部暂停、全部继续和重试全部失败任务。
- 多文件同时下载时，前台通知显示整体进度。
- 修复下载失败后必须重启应用才能重试的问题。
## 1.3.1

- 新增 Gitee 镜像下载线路，改善中国大陆网络下的更新速度。
- 更新下载改为按真实传输速度选择线路，不再只看首包延迟。
- 新增更小的 ABI 专用测试包，并匹配对应校验文件。

## 1.3.0

- 抖音和小红书解析结果补齐描述、作者账号、话题、位置、播放数据、音乐作者与封面等信息。
- 图片新增明确的单张下载、全部下载、动图下载、音乐合成、封面下载和复制原链接入口。
- 音乐信息展示作者和时长，视频线路保留分辨率与文件大小。
- 应用图标更换为首页同款的渐变 C 标识，并适配新版与旧版 Android。
- 新增长描述展开/收起、完整作品信息面板，以及完整的英文 / 简体中文界面。
