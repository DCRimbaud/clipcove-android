# 更新日志

## 1.2.0-rc.2

- GitHub 下载失败时自动尝试多条公共加速线路。
- 设置中可关闭加速线路，改为仅 GitHub 直连。
- 更新包仍强制校验 SHA-256、版本和签名。

## 1.2.0-rc.1

- 下载管理支持搜索、状态筛选和清理已完成任务。
- 下载完成后可以直接打开或分享，无需先另存。
- 收藏支持搜索，并可直接复制原始分享链接。

## 1.1.2

- 更新可在应用内下载、校验并自动打开系统安装器。
- 更新包会校验版本、应用标识、签名和 SHA-256。
- Android 系统仍会在安装前要求一次确认。

## 1.1.1

- 图集支持一键下载全部原图。
- 分享链接到 ClipCove 后可自动开始解析，可在设置中关闭。
- 改进旧收藏和原始作品 ID 的平台识别。

## 1.1.0

- 新增下载版本选择，明确标记原片、转码流和水印风险。
- 小红书默认优先使用无水印原片，只有转码流时会在下载前提醒。
- 收藏可以使用原始分享链接重新解析。
- 新增备份还原、清空全部数据、脱敏诊断导出和手动更新检查。

## 1.0.2

- 小红书视频优先下载原片，减少平台水印。
- 应用品牌正式更名为 ClipCove。

## 1.0.0

- 全新界面、解析结果、收藏、下载和设置体验。
- 支持抖音、小红书、图集、原声与局域网传文件。
